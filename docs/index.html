claim-gate

A publish gate that only ships claims whose cited source actually says them.

How it works

EXTRACT
model

Draft prose goes to the model, which returns claim, quote, and source URL as JSON.

VERIFY
code

Each source URL is fetched, stripped to text, and searched for the quoted string. No model involved.

PUBLISH
code

Verified claims go to the post. Everything else goes to the kill ledger with its reason.

Where it is wrong

All three UNSUPPORTED verdicts landed on JavaScript-rendered or redirecting documentation sites. On those pages the fetcher receives a shell of HTML, so what the checker actually proved is that the quote string was absent from the fetched HTML, not that the claim itself was false. The page text lengths in the ledger show it: 3128 and 5481 characters are far too small to be the real rendered docs page.

Two changes followed. The verdict was renamed to QUOTE_NOT_FOUND so it stops reading as a judgment on the claim, and byte-count logging was added so a suspiciously short fetch is visible in the run log instead of hiding behind a confident verdict.
